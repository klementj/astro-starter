# Exercise 1 — Start the website

## Goal

Run the existing Astro website on your computer.

You are not changing anything yet.

---

## Step 1 — Open the project

Open the repository/project folder.

Find:

```text
package.json
```

You do not need to understand everything inside it.

For now, remember:

> `package.json` contains important information about the project and the tools it uses.

---

## Step 2 — Install the dependencies

Open a terminal inside the project folder.

Run:

```sh
pnpm install
```

This installs the packages that the project needs.

---

## Step 3 — Start Astro

Run:

```sh
pnpm dev
```

Astro should show an address similar to:

```text
http://localhost:4321
```

Open that address in your browser.

You should see the Astro starter website.

---

## What just happened?

`pnpm dev` started Astro's **development server**.

It lets you see the website on your own computer while you work on it.

---

## Checkpoint

Answer in your own words:

```text
Which command starts the website?

What address did Astro give you?

Can you see the website in your browser?
```

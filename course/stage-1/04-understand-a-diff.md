# Exercise 4 — Understand a diff

## Goal

Learn how to see exactly what changed.

---

# What is a diff?

A **diff** shows the difference between an older version and your current version.

You may see something like:

```text
- old heading
+ new heading
```

Usually:

```text
- = removed
+ = added
```

---

## Find your changed file

Open the Git/source-control view in the tool you are using.

You should see that one or more files have been modified.

Open the change.

Look at the diff.

---

## You do not need to understand every character

For now, ask these questions:

- Which file changed?
- Which text was removed?
- Which text was added?
- Does the change match what I intended?

Later, these questions become especially important when Codex changes code.

---

## Important rule

Before accepting a Codex change, always inspect the diff.

Ask:

```text
Did Codex change the file I expected?

Did it change other files?

Did it delete anything unexpected?

Is the change roughly the size I expected?
```

---

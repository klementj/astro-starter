# Stage 1 — Learning the tools

Welcome to the first stage of the project.

You already have a working Astro website.

Your job in Stage 1 is **not to redesign it**.

Your job is to learn how to work with it safely.

---

# What you will learn

By the end of Stage 1, you should have used:

- Astro
- the terminal
- `.astro` files
- CSS
- Markdown
- Git
- Git commits
- Git diffs
- Codex

You are not expected to memorise code.

Instead, you should begin to understand what the different parts of the project are responsible for.

# Working rule

During these exercises, try to follow this cycle:

```text
UNDERSTAND
    ↓
 CHANGE
    ↓
 INSPECT
    ↓
  TEST
    ↓
 COMMIT
```

When Codex is involved:

```text
WORKING VERSION
      ↓
    COMMIT
      ↓
ASK CODEX
      ↓
VIEW DIFF
      ↓
   TEST
      ↓
   COMMIT
```

---

# When something goes wrong

Errors are normal.

Do not immediately ask Codex:

```text
Fix everything.
```

Instead, copy the error and ask:

```text
I am learning Astro and I am a beginner.

I received this error:

[PASTE ERROR HERE]

Do not change anything yet.

Explain:
1. what the error means
2. which file is probably involved
3. what I should inspect first

Use beginner-friendly language.
```

Understanding the problem comes before fixing it.

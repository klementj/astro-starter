# Exercise 3 — Make your first manual change

## Goal

Change something on the website **without Codex**.

This is important.

You need to know that you can edit the project yourself.

---

## Step 1

Open:

```text
src/pages/index.astro
```

Look through the file.

The homepage may also use another component such as:

```text
src/components/Welcome.astro
```

Find some text that you can see on the website.

---

## Step 2

Change one heading to:

```text
My first Astro website
```

Save the file.

Look at the browser.

The page should update.

---

## Step 3

Change it again to:

```text
Jeg bygger min første Astro hjemmeside
```

Save the file.

Look at the browser again.

---

## What just happened?

You changed the website's source files.

Astro noticed the change and updated the development website.

You normally do not have to restart `pnpm dev` every time you edit a file.

---

## Checkpoint

Answer:

```text
Which file did you edit?
I edit the Welcome.Atro file

What happened when you saved it?
It changed the H2 to the new edit

Did you need to restart Astro?
nope 1
```

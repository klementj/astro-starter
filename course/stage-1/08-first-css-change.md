# Exercise 8 — Make your first CSS change

## Goal

Learn that CSS controls the visual appearance of the website.

---

## First find the styling

Ask Codex:

```text
I am learning Astro and CSS.

Inspect the project but do not change anything.

Tell me where the styling for the homepage comes from.

Show me the most relevant CSS file or style section.

Keep the explanation short.
```

Open the file or section Codex identifies.

---

# CSS properties

Look for things such as:

```css
font-size
```

```css
color
```

```css
background
```

```css
padding
```

```css
margin
```

These control different parts of the appearance.

---

## Ask Codex for one visual change

```text
I am learning Astro and CSS.

Make the homepage main heading slightly larger.

Only change the CSS necessary for the heading.

Do not change the page structure.
Do not change colours.
Do not install packages.

Explain which CSS property you changed and what it does.

Run the build afterwards.
```

---

## Inspect the diff

Look at the change before committing.

Try to identify the CSS property Codex changed.

---

## Test

Check the website in your browser.

Does the heading look larger?

Does the rest of the site still look normal?

---

## Commit

Use a message such as:

```text
Adjust homepage heading size
```

---

## Checkpoint

Complete:

```text
CSS controls:

The property Codex changed was:

That property does:
```

# Exercise 7 — Use Codex as a teacher

## Goal

Learn that Codex can explain code without changing it.

---

## Choose some code

Open an `.astro` file.

Choose a small section that you do not fully understand.

Copy it.

---

## Ask Codex

```text
I am learning Astro.

Explain this code in beginner-friendly language:

[PASTE THE CODE HERE]

Explain:

1. what is normal HTML
2. what is Astro-specific
3. what appears on the webpage

Do not change any files.
Do not suggest improvements yet.
```

---

## You do not have to memorise the answer

The goal is to begin recognising patterns.

For example:

```html
<h1>Hello</h1>
```

is normal HTML.

Astro files can also contain code between:

```astro
---
---
```

You will learn more about that later.

---

## Two useful Codex modes

### Inspector

```text
Look at the project and explain it.

Do not modify anything.
```

### Programmer

```text
Make this specific change.
```

Use Inspector mode often.

You do not need to ask Codex to edit something every time you use it.

---

## Checkpoint

Find one thing in the `.astro` file that makes more sense to you now.

Write:

```text
Before, I did not understand:

Now I think it means:
```

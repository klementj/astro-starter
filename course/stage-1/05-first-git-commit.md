# Exercise 5 — Make your first Git commit

## Goal

Create your first safe point in the project history.

---

# What is a commit?

A Git commit is like a named save point.

It records a version of your project in Git's history.

This means you can later see:

- what changed
- when it changed
- why it changed
- previous working versions

---

## Commit your homepage change

Create a commit.

Use a message such as:

```text
Change homepage heading
```

---

## Good commit messages

Good:

```text
Change homepage heading
```

Good:

```text
Add contact section
```

Good:

```text
Fix mobile navigation
```

Less useful:

```text
stuff
```

or:

```text
changes
```

A commit message should briefly explain what changed.

---

## Your history

You should now have something like:

```text
Astro Starter Kit
       ↓
Change homepage heading
```

You now have a safe point.

---

## Important habit

Before asking Codex to make a larger change:

```text
Make sure it works
       ↓
Commit
       ↓
Ask Codex
```

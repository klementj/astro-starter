# Astro Website Course

This folder contains the step-by-step learning course for the project.

The course is divided into stages so that each new group of concepts is introduced gradually.

## Course structure

```text
course/
├── README.md
└── stage-1/
    ├── README.md
    ├── 01-start-the-website.md
    ├── 02-find-the-homepage.md
    ├── 03-first-manual-change.md
    ├── 04-understand-a-diff.md
    ├── 05-first-git-commit.md
    ├── 06-first-codex-change.md
    ├── 07-use-codex-as-a-teacher.md
    ├── 08-first-css-change.md
    ├── 09-first-markdown-file.md
    ├── 10-writing-good-codex-prompts.md
    ├── 11-what-not-to-ask-codex.md
    └── 12-stage-one-review.md
```

## Stage 1 — Learning the tools

Stage 1 introduces:

- Astro
- the terminal
- basic `.astro` files
- CSS
- Markdown
- Git
- commits
- diffs
- Codex

Start here:

➡️ [Stage 1 — Learning the tools](stage-1/README.md)

Later stages can be added alongside it:

```text
course/
├── stage-1/
├── stage-2/
├── stage-3/
└── stage-4/
```

A possible future division is:

- **Stage 1:** Learn the tools
- **Stage 2:** Build with Astro components
- **Stage 3:** Markdown, content collections, and SSG
- **Stage 4:** GitHub Pages and custom domain
